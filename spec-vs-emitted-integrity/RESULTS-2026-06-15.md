# Spec-vs-emitted integrity — the spec-defect failure generalized off the PAN-OS n=1 (2026-06-15)

§9 / H-SPEC-INTEGRITY-01. The hypothesis (from PAN-OS PR #294, Exhibit A): when a vendor's published field
spec disagrees with the data the product emits, a spec-faithful parser inherits the misalignment silently,
and in **positional** formats one disagreement cascades to corrupt every downstream field (present-but-wrong,
no null, no error). This harness measures the **mechanism across format classes** on synthetic records — we
author both the spec and the controlled divergence, so it **demonstrates + quantifies the structural failure's
blast radius by format class**; it is *not* a measurement of real vendors' disagreement prevalence (that needs
real specs + emitted samples — the synthetic-data boundary precludes it, and it stays the hypothesis's open
gate). 12-field PAN-OS-TRAFFIC-shaped schema, 5,000 records/case. `spec_vs_emitted.py`. Tier B.

## Result — silent blast radius per format class

| format | disagreement | SILENT-wrong / record | loud-miss / record |
|---|---|--:|--:|
| **positional CSV** | field omission (the src_user case) | **5.0** | 1.0 |
| positional CSV | type drift (app→"app/port") | 1.0 | 0.0 |
| positional CSV | tail-append (corrected hi-res ts) | 0.0* | 0.0* |
| KV pairs | key rename | 0.0 | 1.0 |
| KV pairs | field omission | 0.0 | 1.0 |
| JSON | key rename | 0.0 | 1.0 |

(of 12 fields/record.) *the tail-append case = the "undelivered fix" dimension — see below.

## What it says

**Positional formats turn one spec/data disagreement into a cascade of SILENT corruption.** Omitting one
mid-record field (the PAN-OS `src_user` at position 6) shifts every downstream field left, so a spec-faithful
parser reads **5 of 12 fields to a wrong-but-present value with nothing firing** (plus 1 loud null where the
record runs short) — exactly Exhibit A's mechanism (PAN-OS dropped `src_user` and ~20 downstream User-ID
fields shifted; here 5 of 12). **Self-describing formats (KV/JSON) inherit the same disagreement but fail
loud and localized** — the renamed/omitted key comes back as **1 null** (a null-check or schema validator
*can* fire), zero silent corruption, no cascade. So the spec-as-defective-contract silent-cascade is a
**structural property of positional formats** (where position *is* the contract), not a PAN-OS quirk — which
is the generalization off the single-vendor instance the hypothesis needed at the mechanism level.

**The tail-append "undelivered fix" case (positional):** when the product appends a corrected field at the
tail (the PAN-OS timezone resolution), the spec-faithful parser reads all 12 spec fields correctly **but
never sees the 13th corrected field** — 0 corruption, but the fix is silently undelivered. My corruption
metric shows 0/0 because the spec fields are intact; the failure here is **"the fix exists in the data but
the spec/parser never reads it"** (a field-not-in-spec is never consumed), the second half of the
hypothesis's mechanism. Noted separately because it is a *missed-improvement*, not a *corruption*.

## What it does to the hypothesis

Generalizes H-SPEC-INTEGRITY-01's **mechanism** off the PAN-OS n=1: the silent-cascade failure is shown to be
a property of the **positional format class** (5-field blast radius from one disagreement) vs self-describing
formats (1 loud null), and the undelivered-fix mode is reproduced. **Confidence stays gated** — this is the
mechanism on *synthetic* authored divergence, which strengthens the structural argument but does **not**
satisfy the open gate (the C1 gate scored across ≥3 *real* vendors' specs vs emitted data, for the
cross-vendor *prevalence* claim). It moves the structural-mechanism leg off n=1; the real-vendor prevalence
leg remains owed.

## Caveats (Tier B)

Synthetic (we author both spec and divergence) — demonstrates + quantifies the *mechanism* and its blast
radius by format class, NOT real vendors' disagreement rates. One schema shape (12-field positional, PAN-OS-
shaped). The blast radius scales with how early the omitted field sits (an omission at position 2 corrupts
more than at position 10) and with field count — the 5/12 here is one corpus design, the *shape* (positional
cascades silently, self-describing localizes loudly) is the transferable finding.
